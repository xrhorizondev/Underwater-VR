# Blue whale audio source

Source: NOAA Pacific Marine Environmental Laboratory (PMEL), Acoustics Program.
Northeast Pacific blue whale call: https://www.pmel.noaa.gov/acoustics/whales/sounds/sounds_nepblue.html
Download: https://www.pmel.noaa.gov/acoustics/whales/sounds/whalewav/nepblue24s10x.wav

The NOAA page identifies this 24-second example as playback at ten times recorded speed. The game uses the first eight seconds slowed to one fifth of that example's playback rate (twice the recorded speed), band-limited, normalized, faded and placed in a 48-second ambience loop with quiet intervals. This is edited game sound design, not an unmodified scientific recording.

Credit: NOAA/PMEL Acoustics Program. No NOAA endorsement is implied.
NOAA public-domain information guidance: https://oceanservice.noaa.gov/about/faq.html and https://csl.noaa.gov/disclaimer.html. The source page does not indicate a separate third-party copyright.

Water, bubble and reef-click layers are original synthesized sound effects; only the whale layer is derived from the NOAA recording. They are not claimed to be recordings of particular fish species.
